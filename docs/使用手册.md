# 个人 AI 知识库 · 新手使用手册

> 这是一份给「完全没跑过这个项目」的人看的上手指南。跟着从头到尾做一遍，你就能把自己的笔记、PDF、网页丢进来，用自然语言搜索和提问了。

---

## 1. 这是什么？

一个装在你自己电脑上的「个人 AI 知识库」（赛博图书馆）。它能：

- **导入资料**：Markdown（.md）、纯文本（.txt）、PDF、网页链接（URL）
- **语义搜索**：不是按关键词搜，而是按「意思」搜，找出最相关的片段
- **智能问答（RAG）**：基于你导入的资料回答问题，并**标注答案来自哪篇文档**
- **板块管理**：把资料分成不同板块（比如「工作」「读书笔记」），可以按板块搜
- **隐私优先**：所有数据只存在你本地，不上传任何地方；AI 密钥只存你自己的电脑

**运行原理一句话**：资料导入后会被切块、算成「向量」存在本地 → 你提问时，先找出最相关的几段 → 把这几段连同问题发给大模型 → 生成带来源引用的回答。

## 2. 开始前的准备

你需要在电脑上装好这三样（都免费）：

| 需要什么 | 用来做什么 | 大概怎么装 |
|---|---|---|
| **Python 3.11+** | 跑后端 | 去 [python.org](https://www.python.org/downloads/) 下载安装，安装时**勾选 "Add to PATH"** |
| **Flutter SDK** | 跑前端界面 | 去 [flutter.dev](https://docs.flutter.dev/get-started/install/windows) 下载解压 |
| **一个 AI 服务的 Key** | 让搜索和问答真正工作 | 你自己选一家大模型服务商，注册拿到 API Key（详见第 5 节） |

> 💡 **小白提示**：装好 Python 后，在 PowerShell 里输入 `python --version`，能看到版本号（3.11 以上）就说明装好了。Flutter 用 `flutter --version` 验证。

## 3. 第一次启动（3 步搞定）

### 步骤 1：启动后端（数据和 AI 的引擎）

打开 PowerShell，依次输入：

```powershell
cd c:\Users\31455\Desktop\YourKnowledgeBase\backend
python -m pip install -e .
python -m uvicorn app.api.main:app --host 0.0.0.0 --port 8000
```

看到类似这样的输出就是成功了：

```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete.
```

**这个窗口要一直开着**，别关。关了后端就停了。

> ✅ **验证后端活着**：另开一个 PowerShell，输入
> ```powershell
> Invoke-RestMethod http://127.0.0.1:8000/health
> ```
> 显示 `status : ok` 就对了。
> 浏览器打开 `http://127.0.0.1:8000/docs` 还能看到自动生成的接口文档。

### 步骤 2：启动前端（图形界面）

**再开一个新的** PowerShell 窗口（后端那个继续开着），输入：

```powershell
cd c:\Users\31455\Desktop\YourKnowledgeBase\frontend
& "$env:USERPROFILE/flutter/bin/flutter.bat" run -d windows
```

第一次运行会编译，可能要等一会儿。编译完会**自动弹出一个桌面窗口**，这就是你的知识库界面。

> 💡 如果上面命令提示找不到 flutter，说明你装 Flutter 的位置不同，把路径换成你实际解压到的位置即可。

**想换成其他形态：**

```powershell
# 网页版（浏览器里打开）
& "$env:USERPROFILE/flutter/bin/flutter.bat" run -d chrome

# 打包成安卓安装包（生成 APK 文件）
& "$env:USERPROFILE/flutter/bin/flutter.bat" build apk
```

### 步骤 3：连接后端

在界面右下角「设置」页里，确认后端地址是 `http://localhost:8000`（默认就是），点「保存地址」。这样前端就和后端连上了。

## 4. 界面怎么用（五页说明）

界面底部（宽屏在左侧）有 5 个入口，从左到右：

### 📥 导入
把资料加进知识库。
- **来源**框里填：本地文件路径（如 `C:\notes\会议记录.md`）或网页链接（如 `https://example.com/article`）
- 可以选择归到某个**板块**（不选也行）
- 点**导入**，完成后会告诉你这是「新建」还是「更新」

### 🔍 语义搜索
按意思找内容。
- 输入问题或描述，比如「上次会议讨论了什么」
- 可以选**返回条数**（3 / 5 / 10）和限定**板块**
- 结果会显示匹配的片段、**相似度分数**和来源文档

### 💬 问答（RAG）
让 AI 直接回答你的问题。
- 输入问题，AI 会基于你的资料作答
- 回答下方会列出**引用来源**，标明答案出自哪篇文档的哪一段
- 👉 这就是「有据可查」——答案不是瞎编的，能追溯到原文

### 📚 板块
管理分类。点右下角「新建板块」创建，也可以编辑、删除。
> ⚠️ 删除板块只是取消分类，文档本身还在库里，不会丢。

### ⚙️ 设置
三块内容：
- **连接**：后端地址
- **会话密钥**：临时填入 AI Key（详见下节）
- **配置状态**：查看当前各项配置（Key 会被打码，只显示最后几位）

## 5. 配置 AI 密钥（重要，但很简单）

搜索和问答需要调用大模型，所以要提供 API Key。**Key 是你自己的，只存你本地，绝不上传。**

### 先准备这两组信息
从你选的服务商那里拿到（任意「OpenAI 兼容」的服务都行）：
- **嵌入服务**（负责把文字变向量，搜索必需）：Key、接口地址、模型名
- **问答服务**（负责生成回答，只在用「问答」页时需要）：Key、接口地址、模型名

### 三种填法，选一种就行

**方式 A：只用这一次（最省心，推荐新手）**
在界面「设置 → 会话密钥」里直接填，点「保存到本次会话」。
- ✅ 好处：不写进任何文件，关掉程序就没了，最安全
- ⚠️ 注意：每次重新打开程序都要重新填一次

**方式 B：写进配置文件（长期使用）**
把 `backend\.env.example` 复制一份改名为 `backend\.env`，填入你的值：

```env
EMBEDDING_API_KEY=你的嵌入Key
EMBEDDING_BASE_URL=https://api.openai.com/v1
EMBEDDING_MODEL=text-embedding-3-small

LLM_API_KEY=你的问答Key
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
```

- ✅ 好处：填一次就行，以后自动读取
- ⚠️ 注意：`.env` 文件别发给别人、别提交到 git（项目已自动忽略它）

**方式 C：用系统环境变量**
设置名为 `EMBEDDING_API_KEY`、`LLM_API_KEY` 等的环境变量。适合进阶用户。

> 🔒 **安全说明**：这三种方式的优先级是——**会话密钥 > 环境变量 > .env 文件**。程序不会把 Key 写进数据库或日志；界面上显示 Key 时一律打码（只露最后 4 位）。

1. 启动后端（第 3 节步骤 1）
2. 启动前端（第 3 节步骤 2）
3. 去「设置」填好会话密钥（方式 A）
4. 去「板块」新建一个板块，比如「测试」

6. 去「搜索」，输入一个和笔记相关的问题，看能不能搜到
7. 去「问答」，提问同一个问题，看 AI 的回答和引用来源

走完这 7 步，你就完整体验了整个闭环！

## 7. 常见问题（遇到报错看这里）

**Q：启动后端报 `uvicorn` 不是命令 / 找不到模块？**
A：先运行 `python -m pip install -e .` 安装依赖；确认你在 `backend` 目录下运行。

**Q：前端点按钮提示「连接失败 / 请求失败」？**
A：多半是后端没启动，或者地址不对。检查后端窗口还开着没，`/health` 能不能访问；再检查「设置」里的后端地址。

**Q：搜索/问答报错说没有 Key？**
A：还没配置 AI 密钥。按第 5 节填一个（推荐方式 A）。注意搜索需要**嵌入**服务的 Key，问答还需要**问答**服务的 Key。

**Q：网页版打不开 / 报跨域（CORS）错误？**
A：项目已自带跨域放行，正常不会报。确认后端是用第 3 节的命令启动的即可。

**Q：数据存在哪里？会被上传吗？**
A：存在 `backend\data\` 文件夹里，**全在你自己电脑上**，项目不含任何遥测/统计上传，放心。

**Q：怎么换一个 AI 服务商？**
A：换掉 Key、接口地址、模型名即可（方式 B 里改 `.env`），代码不用动——它兼容任何 OpenAI 风格的接口。
