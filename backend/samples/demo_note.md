# 语义搜索与 RAG 入门笔记

语义搜索与传统关键词搜索的最大区别在于：它比较的是**含义**而不是字面。
关键词搜索要求查询词和文档用词匹配，而语义搜索先把文本转成向量（embedding），
再在向量空间里找距离最近的片段。

## 为什么需要分块

大模型的上下文窗口有限，而且整篇文档塞进提示词会稀释注意力。
分块（chunking）把长文切成几百字的小段，每段独立向量化。
相邻分块保留少量重叠，可以避免一句话被拦腰切断在两个分块边界上。

## RAG 的基本流程

RAG（检索增强生成）分两条流水线。离线索引流水线负责导入文档、解析、分块、向量化并存入向量库。
在线问答流水线先用同一个向量模型把提问向量化，在向量库里做 Top-K 召回，
再把召回的片段拼进提示词交给大模型生成回答，并且要求回答附上来源引用。

## 一个重要的约束

RAG 回答里的引用必须来自真实检索到的片段，不允许模型编造来源。
否则用户无法核实答案，知识库就失去了可信度。
